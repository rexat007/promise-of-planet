# وعد الكوكب — IMG-F3-02B: مستودع أصول الصور والمعاملات والتزامن

**الحالة:** مواصفة هندسية توجيهية مقترحة، غير ملزمة تلقائيًا لـGoogle AI Studio، بانتظار تنفيذ منفصل ومراجعة المالك.  
**التاريخ:** 2026-10-21  
**المستودع:** `rexat007/promise-of-planet`

## 1. حالة الأساس
- **IMG-F2-03B:** مقبولة من المالك، عقد بيانات محلي مستقل.
- **IMG-F3-01:** تدقيق معماري للحدود الخادمية مكتمل قراءة فقط؛ كشف غياب مستودع أصول الصور وحدود الاعتماد البشري والتسليم العام.
- **IMG-F3-02A + C1:** قبلهما المالك الآن كوحدة تطابق عقد خادمي، **مع قيد مسجل**: نجح 46/46 اختبارًا، ونجح فحص TypeScript المعزول للعقدين، لكن فحص Functions الشامل أعطى Exit 2 بسبب TS5107 مع TypeScript 6 وعدم تثبيت تبعيات functions المحلية. القبول ليس تصريح نشر.
- لا Push ولا Deploy، ولا رفع صور فعلي، ولا اعتماد حقوق خادمي.

## 2. مصدر الحقيقة
- Google AI Studio الحالي مصدر التغييرات المحلية غير المرفوعة؛ GitHub مصدر النسخة المرفوعة فقط.
- لا يُفترض وجود `.git` أو وصول Studio إلى GitHub؛ لا يجلب ملفًا بالمسار أو SHA. عند الحاجة إلى GitHub يُطلب رابط HTTPS مباشر ومتحقق لكل ملف، وإلا STOP.
- كل بصمات SHA أدناه للتحقق من الملفات المحلية فقط.

## 3. المقصود بهذه الوحدة المتوسطة
إنشاء **طبقة حفظ أصول الصور الخادمية غير المفعّلة** مع واجهة مستودع وتعاملات تنافسية، ونموذج اختبار داخل الذاكرة. الهدف إثبات `create-if-absent` و`read` و`compare-and-swap`، ومنع الكتابة فوق المراجعات المتزامنة، واستعادة السجل من مصدره مع فحص عقد البيانات المعتمد. **لا تُفعّل أي دوال HTTP/callable، ولا تُنفذ انتقالات الحقوق أو سجلات تدقيق إنتاجية** في هذه الوحدة.

## 4. حدود الثقة
- بيانات الأصل لا تُعدّ موثوقة لمجرد تخزينها؛ يُتحقق من كامل `EditorialImageAssetMetadata` عند الدخول والخروج.
- `assetId` معرف مخزن مطابق للمستند؛ الإنشاء يرفض التكرار، والتحديث لا يغير الهوية أو أصل الملف أو الحقوق.
- لا تعديل بدون شرط توافق صريح على نسخة السجل/تاريخ تحديثه؛ في حال سباق التعديل يرفض واحد من المتنافسين بصورة حتمية.
- إن استخدم `updatedAtIso` لشرط التزامن يجب أن تكون الصيغة الزمنية دقيقة ولا يعتمد عليه وحده إن أمكن تكراره؛ **يفضّل رقم إصدار داخلي للمستودع** غير مضاف إلى عقد الأصل المقبول، شرط أن يبقى بحدود الحفظ ولا يسمح للعميل بتزويده.
- لا كتابة بيانات حقيقية إلى Firestore من اختبار؛ الاختبارات بحقن واجهات وهمية/ذاكرة.
- لا إصدار أحكام حقوق، ولا استنتاج صلاحية المراجع من `reviewedByUid`.

## 6. تقييد التنفيذ وأسلوب اختيار الملفات
**قائمة سماح مبدئية** (يتحقق Studio قبل أي كتابة من عدم وجود ملفات تعارض ومن أن الأسماء لا تصطدم بالخدمات الحالية):
- `functions/src/news/editorialImageAssetRepository.ts` — عقد المستودع ونتائج الأخطاء.
- `functions/src/news/inMemoryEditorialImageAssetRepository.ts` — تنفيذ ذري داخل الذاكرة للاختبارات.
- `functions/src/news/firestoreEditorialImageAssetRepository.ts` — تكييف معاملات Firestore عبر حقن اعتماديات ملائم مع نمط المستودعات الفعلي.
- `src/services/editorialImageAssetRepository.test.ts` — اختبارات الحفظ والتزامن والأخطاء مع محاكيات بدون اتصال خارجي.

هذه **مقترحات مسارات وليست إثباتًا لوجودها أو ملاءمتها**. إذا تعارضت واجهات Firestore الموجودة مع اختبار خالٍ من الاعتمادات، يوقف Studio قبل الكتابة ويقدم اقتراح تعديل محدود للقائمة؛ لا يثبت حزم ولا يعدّل إعدادات TypeScript تخمينيًا. لا يُسمح لملف جديد بالكتابة في قواعد Firebase أو `index.ts`.

## 7. اختبارات القبول
- إنشاء ناجح مرة واحدة، والتكرار يرفض.
- قراءة السجل تعطي نسخة مستقلة ومتحققًا من صحتها، ومفقود يعيد نتيجة واضحة.
- تحديث مشروع مشروط بإصدار/نسخة حالية، والتحديث القديم يُرفض بلا أي كتابة جزئية.
- سباق متزامن لتحديثين: نجاح واحد فقط.
- رفض السجل الخاطئ عند الكتابة والقراءة، وعدم تجاهل أخطاء القراءة/المعاملات.
- رفض تحديث `assetId` والحقوق ومراجع Storage من طريق المستودع العام؛ لا فتح منفذ تعديل جديد غير محمي.
- انعدام تعديل الدخل واختبار عدم حدوث كتابة Firestore فعلية.
- نجاح Vitest للأجزاء المعنية، وفحص TypeScript مستقل حيث تسمح البيئة، مع إبلاغ مستقل عن فشل فحص Functions الكامل وعدم وصفه PASS.

## 8. شرط التوقف والبوابات اللاحقة
- STOP إذا تغير عقد الصور المقبول، أو كانت الملفات المقترحة موجودة بمحتوى غير متوقع، أو تطلّب التنفيذ تغيير `functions/tsconfig.json` أو تثبيت حزم أو كتابة خارج قائمة السماح.
- إن لم يسمح فحص المصدر بتنفيذ مستودع Firestore آمن ضمن تلك الحدود، عُد بتقرير انسداد دون كتابة جزئية أو تقليد غير آمن.
- **لاحقًا وبقرار منفصل:** توثيق أحداث التدقيق الدائمة وعمليات حقوق بشرية ذرية وخاضعة لـ`ManageRights`، ثم رفع الصور والتحقق من البايتات، ثم بوابة أخبار V2 والتسليم العام والإلغاء.
- إنهاء الاختبارات لا يجيز Push أو Deploy. مراجعة GitHub Sync وقبول المالك مستقلة.
